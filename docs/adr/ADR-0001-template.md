# ADR-0001: Architecture decision template

## Status
Accepted

## Context
The team needs a consistent record for architectural decisions and exceptions.

## Decision
We will document each intentional module boundary exception in a dedicated ADR.

## Consequences
- Decisions become discoverable.
- Exceptions remain explicit and reviewable.
- The codebase keeps a documented architectural trail.

## Review
This ADR should be reviewed during refactors or when the exception is removed.
